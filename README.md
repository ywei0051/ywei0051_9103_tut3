# Quiz 8 – Halftone Style Inspiration & Coding Technique

## Part 1: Imaging Technique Inspiration

**Technique:** Halftone / Ben-Day dots (comic printing effect)

**Example source:** *Spider-Man: Across the Spider-Verse*  
The film heavily uses halftone patterns in shadows, backgrounds, and character shading (e.g., Spider-Verse CMYK Halftone Field and Miles vs Spot)

**What I want to incorporate:**  
The use of **halftone dots** to replace smooth gradients. I want to apply this to shadows and environmental elements in my project.

**Why it’s beneficial:**  
Halftone creates a strong graphic, print‑like aesthetic that matches the assignment’s focus on stylized visual language. It adds texture, retro comic energy, and emotional tone without realistic rendering.

## Part 2: Coding Technique Exploration

**Coding technique:** Dithering / Halftone simulation (JavaScript + HTML5 Canvas)
**How it helps achieve the effect:** This technique processes an image pixel by pixel to simulate the dot-based comic print style seen in *Across the Spider-Verse*. By mapping pixel brightness to a pattern of dots, it creates a retro, print‑like aesthetic without smooth gradients.
